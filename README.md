# homebrew-tap

Homebrew tap for [fredoliveira](https://github.com/fredoliveira)'s tools.

## Install

```sh
# Recall CLI (MTGA log uploader for 17Lands):
brew install fredoliveira/tap/recall

# Recall desktop menu-bar app (macOS):
brew install --cask fredoliveira/tap/recall-desktop
```

## Formulae & casks

- **recall** — Rust port of the 17Lands MTGA log client (formerly `seventeenlands-rust`).
- **recall-desktop** (cask) — Recall menu-bar app (formerly `seventeenlands-desktop`).
  Source: https://github.com/fredoliveira/recall
